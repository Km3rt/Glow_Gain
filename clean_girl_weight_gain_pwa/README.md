# Glow & Gain — Clean Girl Weight Gain PWA 🌸✨

Eine Ästhetische iOS-PWA zum Zunehmen & Einkaufsplanung im Clean-Girl-Design.

## Features
- **Pantry & Einkaufsliste:** Zutaten abtippen, als vorhanden oder fehlend markieren.
- **Tagesplaner ("Morgen zubereiten"):** Zutaten für den nächsten Tag planen & High-Calorie Shake Rezepte.
- **Offline & PWA:** Läuft 100% lokal im Browser/auf dem Smartphone ohne Server.
- **JSON Backup:** Daten einfach sichern und übertragen.

## Deployment auf Cloudflare Pages / GitHub Pages
1. Dieses Repository auf GitHub hochladen.
2. Auf [Cloudflare Pages](https://dash.cloudflare.com/) gehen -> **Create Application** -> **Pages**.
3. Mit GitHub verbinden, Repository auswählen und **Deploy** klicken.
4. Fertig! 🚀
